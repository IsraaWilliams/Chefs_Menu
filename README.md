### What The App Does
This React Native app helps Chef Christoffel manage his restaurant menu. It displays total dishes, total value, and average price. Chef can filter by course and add/remove dishes with live stats update.

## Features Implemented
- Header with restaurant name + student details
- Stats: Total Dishes, Total Value (R), Average Price (R)
- Filter by Course: All | Starter | Main Course | Dessert
- Add Dish Form with validation:
    - Name required
    - Description 10-100 chars
    - Course required
    - Price > 0
- Remove Dish button
- Scrollable menu list
- Live update of stats
